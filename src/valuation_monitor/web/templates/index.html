Order of the home page

Move a stock with its buttons, or drag it on a computer. A hidden stock is only left off this page: its data is still updated and its own page still works. Save stores the order for every device; Close without saving keeps the saved order.

    GitHub token for saving (needed once on each device)

    Saving starts the workflow "Save the home page order" of the repository, which writes the new order into config.yaml and republishes the site. GitHub needs a token for that:

    1. On GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens, and click "Generate new token".
    2. Repository access: "Only select repositories", and choose this repository only.
    3. Permissions: Repository permissions, "Actions": "Read and write". Nothing else is needed.
    4. Copy the token and paste it below. It is kept in this browser only and sent to GitHub only.
